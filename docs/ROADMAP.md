# Roadmap

- v0.2: lexical nested representation, round-trip tests, conflict handling, optional AI explanations, local import/export.
- v0.3: Lean InfoTree/LSP adapter with genuine tactic state, multiple goals, local hypotheses and references. Build a benchmark with reviewed mathematical narratives.
- v0.4: editable prose document with source-linked spans, incremental patches and explicit alignment review. Add theorem selection and project browsing.
- v0.5: VS Code extension backed by the same core. Prototype Tauri desktop shell after local proof-checker lifecycle and security are settled.
- v1.0: research workspace with multi-document collaboration, mathematical exposition, LaTeX export and reliable installation.

Non-goals: claiming arbitrary natural-language equivalence; solving hard theorems for users; exposing local Lean execution as an unauthenticated web service.
