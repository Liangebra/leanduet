Compose a multi-step proof · 组合推理

Each intermediate result extends the scope. Specify ordered premise names; omit the proposition to infer it with Lean, or annotate it with $LaTeX$. Use ? instead of a rule to request Lean proof search. An intermediate hole requires its proposition. Review and check the generated candidate.

Formula sequence: enter one $formula$ per line. The last is the conclusion; earlier formulas become intermediate goals. Names such as hq : $Q$ are optional.

Extract a lemma

Abstract the selected proof over its dependency-closed context. Local definitions remain lets. A standalone source preview is shown only after compilation and structural comparison; the original proof is not modified.

Semantic IR · kernel judgment
Inspect the selected Lean term, its type, all local declarations, universe levels and the elaborated formula if provided. Metadata is omitted. Scope validation is not a type checker.
Generated source may change the header spelling and tactic layout. Lean checks definitional equality of the statement. The original is not changed until you apply.
Mathematical exploration
Write freely: questions, incomplete arguments, conjectures, counterexamples, notation of your own. No grammar or proof obligations are imposed here. Notes are local and unverified; editing them does not alter the Lean source.
Optional: select a supported LaTeX formula to stage it in a selected typed goal. This never applies a proof.
