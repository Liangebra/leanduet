# Contributing

Thank you for helping build an editor that puts mathematical understanding first.

1. Fork and clone the repository.
2. Run the quick start in README and the Node/Python tests.
3. Open a focused issue for substantial changes, describing mathematical intent and acceptance criteria.
4. Submit a PR with an example and regression test. If a Lean claim is made, check it using the pinned toolchain or state the exact environment.

We welcome reviewed informal proofs and counterexamples, Lean metaprogramming, UI design, accessibility, documentation and translations. Never label an AI narrative as verified merely because Lean accepts the source. Keep unknown fragments intact. Never silently discard user edits or weaken theorem statements.

Be respectful, critique ideas rather than people, and disclose AI assistance when relevant. Contributions are under the MIT license.
